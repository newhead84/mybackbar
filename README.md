# 위스키 백바

국내 위스키바에서 자주 보는 위스키를 종류별 선반에 진열한 정적 페이지입니다.

- 병 이미지: 위키미디어 공용의 자유 라이선스 사진을 참고해 AI(GPT 이미지)로 다시 그림. 참고 사진의 작가·라이선스는 페이지 맨 아래 목록에 있습니다(CC BY-SA 사진에서 나온 이미지는 같은 라이선스).
- 공유 미리보기 이미지(`og.jpg`)는 위 병 이미지 일부를 합성한 것이라 같은 출처·라이선스를 따릅니다.
- 글꼴: Pretendard (SIL OFL 1.1, 원문 `fonts/Pretendard-OFL.txt`), Space Grotesk (Google Fonts, OFL).
- 내 관심(★)과 비교 목록은 방문한 브라우저에만 저장되고 서버로 보내지 않습니다.
- 병 소매가는 2026년 11월 국내 주류 판매처(주로 데일리샷, 일부 대형마트·주류 전문점)에 올라온 가격을 모은 범위입니다. 바에서 파는 한 잔 값이 아니며, 판매처·환율·행사에 따라 달라집니다.
- 맛 표현과 수치는 일반적으로 알려진 내용을 줄인 것이며 제품 판에 따라 다를 수 있습니다.
